# MegaTools
Military & federal pay calculators using official sources.

Use Node 22 and pnpm. Copy `.env.example` to `.env.local` and configure the values.

Commands: `pnpm dev`, `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm build`, `pnpm data:all`, `pnpm data:check`.

See `AGENTS.md` for project rules and `docs/STATUS.md` for progress.

Available: per diem ZIP/city rates and trips, VA ratings/compensation, GI Bill, retirement, military time, and verified-input BAH/pay/PCS/PPM budgets. See docs/DATA-BLOCKERS.md for incomplete official automation and docs/DEPLOY.md for deployment. The local preview runs at http://127.0.0.1:3000/.
